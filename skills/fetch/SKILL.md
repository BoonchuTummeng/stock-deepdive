# ดึงเอกสารต้นฉบับ

ดึง **เอกสารที่บริษัทหรือหน่วยงานกำกับออกเอง** เท่านั้น — ไม่ดึงบทวิเคราะห์ ไม่ดึงข่าว ไม่ดึงความเห็นใคร
เพราะสองอย่างนั้นเป็นคนละชั้นของความน่าเชื่อถือ และการเอามาปนกันคือต้นทางของการวิเคราะห์ที่ผิด

## ก่อนเริ่ม — แยกให้ออกว่าเป็นหุ้นตลาดไหน

ถามผู้ใช้ถ้าไม่ชัด อย่าเดา ชื่อย่อซ้ำกันข้ามตลาดได้

## หุ้นสหรัฐ

```
python "${CLAUDE_PLUGIN_ROOT}/bin/fetch_us.py" <TICKER> --out ./data/<TICKER>
```

**ครั้งแรกต้องมีอีเมลจริง** — SEC บังคับให้ระบุตัวตนในทุกคำขอ ไม่งั้นบล็อก
ถ้ายังไม่ได้ตั้ง ให้ถามผู้ใช้แล้วส่งผ่าน `--contact "ชื่อ อีเมล"` หรือแนะนำให้ตั้ง `SEC_CONTACT` ไว้ถาวร

จะได้: 10-K · 10-Q · 8-K พร้อมใบแนบข่าวผลประกอบการ · DEF 14A
บริษัทต่างชาติที่จดทะเบียนในสหรัฐจะสลับเป็น 20-F · 6-K ให้เอง

🌟 **ไฟล์ที่มีค่าที่สุดคือ `companyfacts.json`** — ตัวเลขงบทุกตัวที่บริษัทเคยรายงาน ย้อนหลังทั้งหมด
พร้อมป้ายว่าเป็นงวดไหน หน่วยอะไร ⇒ **ใช้ตัวนี้แทนการอ่านเลขจากงบ HTML เสมอ** เพราะอ่านผิดไม่ได้
เปิด `companyfacts_index.txt` ก่อนเพื่อดูว่ามีรายการอะไรให้ใช้บ้าง แล้วค่อยเจาะเข้าไฟล์ JSON

## หุ้นไทย

```
python "${CLAUDE_PLUGIN_ROOT}/bin/fetch_th.py" <SYMBOL> --out ./data/<SYMBOL>
```

จะได้งบย้อนหลังหลายงวด แต่ละงวดมี งบการเงิน · **หมายเหตุประกอบงบ** · รายงานผู้สอบบัญชี
สคริปต์แปลง `.docx` และ `.xlsx` เป็นข้อความให้อัตโนมัติ อ่านต่อได้เลย

🔴 **ตรวจชื่อบริษัทที่สคริปต์พิมพ์ออกมาทุกครั้ง** — ระบบ iDisc ครอบคลุมบริษัทที่ออกหุ้นกู้ด้วย
ชื่อย่อจึงชนกับบริษัทที่ไม่ได้จดทะเบียนในตลาดได้ ถ้าชื่อไม่ตรงกับที่ผู้ใช้ต้องการ ให้หยุดแล้วถาม

🌟 **หมายเหตุประกอบงบคือของที่หายากที่สุดและได้มาฟรี** — การตั้งสำรอง รายการกับบุคคลที่เกี่ยวข้อง
เกณฑ์การรับรู้รายได้ ล้วนอยู่ในนั้น ไม่ใช่ในตัวงบ

## หลังดึงเสร็จ — รัน `extract.py` เสมอ

```
python "${CLAUDE_PLUGIN_ROOT}/bin/extract.py" ./data/<TICKER>
```

ใช้เวลาไม่กี่วินาที แล้วได้ `MANIFEST.md` = สารบัญว่าอะไรอ่านได้ อยู่ไฟล์ไหน กี่ตัวอักษร
🔴 และบอกว่า **หน้าไหนของ PDF เป็นภาพสแกน** — หน้าพวกนั้นดึงข้อความไม่ได้ ต้องเปิดอ่านด้วยสายตา
ถ้าไม่รู้ล่วงหน้า จะเสียเวลาค้นหาของที่ไม่มีวันเจอในข้อความ

สคริปต์ยัง **แกะตาราง Excel ที่ฝังอยู่ในหมายเหตุประกอบงบ** ออกมาให้ด้วย ซึ่งเป็นที่ที่ตัวเลข
อย่างการตั้งสำรอง อายุลูกหนี้ และรายการกับบุคคลที่เกี่ยวโยงซ่อนอยู่

รายงานผู้ใช้ว่าได้อะไรมาบ้าง กี่งวด และ **บอกตรง ๆ ว่าอะไรที่ดึงไม่ได้** — บทถอดเทปประชุมนักลงทุน
สไลด์นักลงทุน และราคาหุ้น ไม่มีในแหล่งเหล่านี้ ถ้าผู้ใช้มีไฟล์เองให้วางไว้ในโฟลเดอร์เดียวกัน

## กฎ

- **ห้ามดึงจากแหล่งที่ต้องเสียเงินหรือ login** แล้วเอามาแจกต่อ
- ถ้าดึงไม่สำเร็จ ให้บอกว่าล้มเหลวตรงไหน อย่าเงียบแล้วเดินต่อด้วยข้อมูลที่ไม่มี
- เอกสารที่คนอื่นวิเคราะห์ไว้ = เบาะแส ไม่ใช่ต้นฉบับ ถ้าจะใช้ต้องติดป้ายให้ชัด
