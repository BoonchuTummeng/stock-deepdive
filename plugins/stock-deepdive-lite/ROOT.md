# `<ราก>` คืออะไร และหาอย่างไร

สกิลในปลั๊กอินนี้เรียกสคริปต์ Python ด้วย path แบบ `<ราก>/bin/...`

> **`<ราก>` = โฟลเดอร์ที่มี `bin/` กับ `skills/` อยู่ด้วยกัน**

เหตุที่ไม่ฝัง path ตายตัวไว้ เพราะปลั๊กอินตัวเดียวกันนี้ถูกติดตั้งได้จากหลายเครื่องมือ
ซึ่งแต่ละตัวเก็บไฟล์ไว้คนละที่ · หาให้ถูกครั้งเดียวตอนต้นงาน แล้วใช้ซ้ำได้ตลอดรอบ

---

## Claude Code

มีตัวแปรให้อยู่แล้ว ใช้แทนได้ตรง ๆ ไม่ต้องหา

```
${CLAUDE_PLUGIN_ROOT}
```

## Codex

สกิลถูกโหลดจาก `<ราก>/skills/<ชื่อสกิล>/SKILL.md` ⇒ **ถอยขึ้นสองชั้นจากไฟล์ SKILL.md ที่กำลังอ่าน**

ถ้าไม่รู้ path ของ SKILL.md ให้หาจากแคชที่ติดตั้งไว้ ตัวที่เวอร์ชันใหม่สุด:

```bash
ls -d ~/.codex/plugins/cache/*/stock-deepdive-lite/*/ | sort | tail -1
```

## Clone repo มาใช้ตรง ๆ (ไม่ผ่านระบบปลั๊กอิน)

`<ราก>` คือโฟลเดอร์ repo ที่ clone มา — ถ้า `cwd` อยู่ในนั้นอยู่แล้ว ใช้ `.` ได้เลย

---

## 🔴 ตรวจหนึ่งครั้งก่อนเริ่มงานจริง

```
python "<ราก>/bin/extract.py" --help
```

ผ่าน = หาถูก · **error = หาผิด ให้หาใหม่ ห้ามเดาต่อ**
การเดา path ผิดแล้วเดินต่อ จะไปโผล่เป็นความล้มเหลวตอนกลางงาน ซึ่งเสียเวลากว่าการตรวจตรงนี้มาก
